# Reporting

- Reply in the language the user wrote in. Everything that leaves the conversation — files, commits, PRs, tickets, comments — is in English. In a long session, check the language before each final message.
- Lead with the result and any decision needed from the user, and fit it on one screen. Details only on request.
- Explain a project term or a piece of jargon in a short clause the first time it appears in a session.
- No preamble, no recap of what did not change, no apology. When corrected: one line on what was wrong, then the fix; if the correction is a durable rule, propose where to record it.
- Memory holds facts that live nowhere else, never rules. Every memory write or deletion goes through the permission prompt.
