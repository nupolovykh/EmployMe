# 2026-08-27 — Phase 0 exits: the source-qualification gate is met

**Gate.** Phase I could not start with fewer than four sources at level `spike`, at least two of
them Tier A, at least four cleared for public display. On 2026-08-26 the EM-45–49 spikes put five
sources at `spike` — Greenhouse and Lever (Tier A), Himalayas, Jobicy and Arbeitnow (Tier B) — and
four were cleared. Himalayas was not: its terms require prior written approval, found live during
the spike. The gate was met without it. Tag `phase-0` sits on the merge of PR #14.

**EM-46 was reopened and re-run.** The first Lever spike sampled a guessed token (`palantir`)
instead of the registry companies its own criteria required. It was re-run on 2026-08-27 against
`qonto`, `remofirst` and `peerspace` (200/200/200, 44 postings). EM-46 also asked for a committed
live-endpoint test; that needed the Phase II test infrastructure (EM-23), so the obligation moved
to the nightly contract test (EM-55) instead of pulling xUnit into Phase 0.

**The target-company registry changed shape (EM-50).** Collecting 30 companies before any spike
ran was backwards: the Tier A spikes had no registry to draw from and were validated against
whatever token answered (GitLab, Palantir). The registry became a small live-verified seed — three
companies per ATS — that grows only from applications actually sent.

**Salvaged code and the gate (EM-56).** EM-11, EM-15 and EM-16 were written before Revision 2,
against the hh.ru plan, and carried forward rather than rewritten. They are read-path code with no
source integration, so they cannot violate a gate about source qualification. The gate binds
ingest work (EM-52/53), which did not start until the four spikes landed. Later gates are read the
same way: they constrain new work against external sources, not the salvage of code that touches
none.

**Adapter types (EM-53, 2026-08-26).** The three Tier B rows had read `json_api`, a placeholder.
Their payloads share nothing (`jobs[]` vs `data[]`, `id` vs `slug`), so each source got its own
adapter class.
